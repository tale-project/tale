# English edits

These are language examples, not verified product specifications.

## Name an action

Weak: “You have the ability to perform a review of the document.”

Better: “Review the document.”

Add what to look for when it is not obvious. Do not pad a clear instruction with a claim that it
is easy.

## Connect a condition to its action

Weak: “Run the command. Make sure the service is running first.”

Better: “Start the service before running the command.”

The prerequisite arrives before the dependent action. A real example must name the service,
command, and verification using observed behavior.

## Offer a useful next task

A descriptive link to the task the reader will need next can be the complete ending. It does not
need an “In summary” paragraph or a sentence announcing that more documentation exists.
