# German edits

These illustrate language choices, not verified UI workflows or product guarantees.

## Remove a literal construction

English: “Review the changes before you run the command.”

German: “Prüfe die Änderungen, bevor du den Befehl ausführst.”

The dependent action stays conditional on the review. German uses a natural subordinate clause;
it does not need to copy the English word order.

## Keep a technical identifier exact

English: “Set `TALE_CONFIG_DIR` to the directory that contains the configuration.”

German: “Setze `TALE_CONFIG_DIR` auf das Verzeichnis mit der Konfiguration.”

The identifier stays unchanged while the surrounding sentence becomes native German. Actual
configuration behavior still needs verification before using this in a product guide.

## Remove redundant success wording

Weak completion notice: “Datei erfolgreich gespeichert.”

Better completion notice: “Datei gespeichert.”

A concise completion notice names the result. A diagnostic sentence about whether saving
succeeded may need different wording; do not replace words without context.
