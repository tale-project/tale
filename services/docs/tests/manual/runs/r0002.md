## Scope

This change-scoped round checked rewritten reader journeys, localized navigation,
search, code copying, diagrams, screenshots, and the author preview. English,
German and French pages were rendered on desktop and phone widths. Video
production, playback and caption review were excluded from this task.

## Baseline

This was an exploratory authoring round, not an untouched-tree full-catalogue
baseline. Content checks ran during writing, so a stale generated frontmatter
manifest was regenerated before the closing pass. A generated-artifact test
also exceeded its five-second budget while compiling the same corpus four
times; the suite now compiles one immutable fixture and checks every Markdown
artifact instead of sampling five.

### R2-1 · Article body lost during preview updates

**Repro:** Open a content page, edit its Markdown, or regenerate frontmatter.
React hot replacement could reset the lazy body cache without rerunning the
route loader. The docs Vite plugin now invalidates changed content modules and
requests a client full reload for the content tree and generated manifest.
An actual temporary paragraph appeared after saving and disappeared after
restoration, with the article body present throughout the repeat checks.

**Pinned by:** `lib/content/reload-content.test.ts` and a real dev-server
edit/restore browser probe. Ordinary React source hot updates remain separate.

### R2-2 · Long inline code overflow

**Repro:** Open the German approval-policy guide at 390px. Its
`TALE_CONFIG_DIR/<orgSlug>/governance/approval-policy.yml` inline path extended
past the content column. Shared inline code now permits wrapping oversized
strings. Copying keeps the original text; fenced examples scroll internally.

**Pinned by:** `tests/e2e/specs/markdown.spec.ts` in all three languages.

### R2-3 · Untranslated Markdown chrome

Copy buttons, heading links, callout names, code-group labels and diagram
controls used literal English text. They now use shared message catalogs,
including a sparse Swiss German overlay. This also closes the copy-control
portion of the historical finding carried into R1.

**Pinned by:** shared `markdown/copy-controls.test.tsx`,
`markdown/components/chrome-locales.test.tsx` and the rendered Markdown spec.

### R2-4 · Untranslated search ancestors

The URL breadcrumb helper localized only its first path segment. Docs search
now uses the existing navigation hierarchy for each indexed `locale:slug`,
with the sidebar's translated group labels. The URL fallback remains for
results outside that hierarchy.

**Pinned by:** `app/features/search/dialog.test.tsx`, plus real German and
French index searches in the running docs site.

## Not reached

The full accessibility catalogue, screen-reader announcement quality, real
mobile devices, offline/update choreography and videos were not exercised in
this round. External vendor setup and production deployment outcomes require
the corresponding operator environment; a rendered guide is not that proof.

## Verdict

All four observed reader/preview defects were fixed and re-driven. The
content is grounded in the isolated platform walkthrough and source audit;
remaining environment limits are explicit in the platform round. The closing
repository check passed all 43 tasks with Bun 1.4.2 and two concurrent tasks.
The production build generated 414 pages; all 18 browser tests, nine prerender
tests and 24 sampled desktop/mobile render checks passed against the final
artifact. The manual-test guard and SAST also passed. This is a scoped
documentation round, not a full platform or device certification.
