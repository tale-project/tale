## Findings

The incoming reference facts needed the same task-oriented treatment as the
existing overhaul. The first refreshed library image exposed old manual-test
filenames. The final capture selects indexed uploads through the real filters,
keeps the active-filter indicator visible, and retains all underlying records.
No product behavior was hidden or changed for the screenshot.

The rendered review also exposed missing Frame captions: HTML parsing discarded
the obsolete native `frame` tag before the component could render. The shared
renderer now protects standalone authored Frame tokens when the docs component
registry is supplied. Three parser regressions failed before the fix and passed
afterward. The EN/DE/FR browser regression checks visible captions, keyboard zoom,
Escape and restored focus. Source images and authored caption text remain intact.

A final visual read moved the new folder-scope table from the general caching
section into its canonical Hub document section, keeping the reference organized
around the resource being used.
