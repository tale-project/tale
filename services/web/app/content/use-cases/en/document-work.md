Reports, presentations, and spreadsheets usually pass through several people before they are ready. Tale gives the team a shared place to define the assignment, delegate file work to an agent, and review the deliverables.

## Make the output part of the brief

Create a task with the source files, target audience, required format, and acceptance criteria. Ask for a board presentation, a monthly report, a proposal draft, or a spreadsheet analysis. Specify which figures and statements must be checked against the supplied material.

Tale's document skills support Word, PowerPoint, Excel, and PDF work in an agent sandbox. Equip the appropriate skill and tools for the task. The agent can return files as task deliverables, together with a report that explains the work performed. Text recognition for scanned PDFs is not included in the built-in document tooling.

## Example: prepare a monthly business review

1. **Collect the inputs.** Attach the approved numbers, earlier report, and presentation guidelines.
2. **Assign the analysis.** Ask an agent for a draft with source references, calculations, and a list of unresolved questions.
3. **Review the deliverables.** Check the numbers, formulas, narrative, and rendered layout in the intended file applications.
4. **Request a revision.** Mention the assigned agent in a task comment with your corrections so it works from the team's feedback and the same brief.

For independent outputs, separate agents can work in parallel within configured sandbox capacity. Give a final synthesis task the files it needs rather than assuming that every agent has seen the others' work.

## Keep responsibility visible

The project board shows who owns the assignment and which results need review. That is useful when finance, operations, marketing, or leadership contribute to the same package. Your team decides when the material is accurate enough to distribute.

Tale coordinates the assignment and its review. Existing document editors remain useful for final adjustments and collaborative editing inside a file. High-stakes figures and claims still need a qualified reviewer.
