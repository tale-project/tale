Start with a problem your team needs to solve. In Tale, people organize the work in projects, delegate suitable tasks to AI agents, and review the results together. The same collaboration model applies across different kinds of work.

## Choose a starting point

| Your team's work | A first project to try |
| --- | --- |
| [Marketing campaigns](/use-cases/marketing-campaigns) | Turn a launch brief into sourced research, campaign drafts, and a publishing handover |
| [Software development](/use-cases/software-development) | Take a website, app, or internal tool from a clear brief through implementation and review |
| [Research](/use-cases/research) | Split a business question into investigations and a decision brief with traceable sources |
| [Document work](/use-cases/document-work) | Prepare a report, presentation, or spreadsheet with files and feedback attached to the task |
| [Operations](/use-cases/operations) | Give recurring requests, process improvements, and handovers clear owners and deliverables |

These are example workflows, not claims about customer results. Start with the tools, references, and review process your team already uses.

## From a shared brief to a reviewed result

Define the outcome and acceptance criteria. Give each task an owner, configure an agent with the tools it needs, and start the work. Teammates follow progress and mention the assigned agent in task comments to give it new instructions. Review the report and deliverables, then request changes or move the work forward.

Independent agents can work in parallel within configured sandbox capacity. Use explicit tasks and handovers for dependencies rather than assuming every agent shares the same context.

## Keep the work visible as you add agents

Tale's focus is the collaboration around execution: who is working on what, what the team asked for, and which results need attention. Supported runtimes let you bring compatible API or subscription credentials. Self-hosting and private-model options give teams additional deployment choices.
