Rapports, présentations et tableurs passent souvent entre plusieurs mains avant d’être prêts. Tale donne à l’équipe un espace partagé pour définir la demande, déléguer le travail sur les fichiers à un agent et examiner les livrables.

## Décrire le livrable dans le brief

Crée une tâche avec les fichiers sources, le public visé, le format demandé et les critères d’acceptation. Demande une présentation pour la direction, un rapport mensuel, une proposition ou une analyse de tableur. Précise les chiffres et affirmations à vérifier dans les documents fournis.

Les skills documentaires de Tale prennent en charge Word, PowerPoint, Excel et PDF dans la sandbox d’un agent. Équipe-le du skill et des outils adaptés. L’agent peut rendre des fichiers comme livrables de la tâche, avec un rapport expliquant le travail réalisé. La reconnaissance de texte pour les PDF numérisés n’est pas incluse dans les outils documentaires intégrés.

## Exemple : préparer une revue mensuelle d’activité

1. **Réunir les données.** Joins les chiffres approuvés, le rapport précédent et les consignes de présentation.
2. **Confier l’analyse.** Demande à un agent un brouillon avec les références, les calculs et les questions non résolues.
3. **Examiner les livrables.** Vérifie chiffres, formules, raisonnement et mise en page dans les applications prévues pour ces fichiers.
4. **Demander une révision.** Mentionne l’agent affecté dans un commentaire avec tes corrections pour qu’il poursuive avec les retours de l’équipe et le même brief.

Plusieurs agents peuvent préparer des livrables indépendants en parallèle selon la capacité configurée des sandboxes. Donne à la tâche de synthèse les fichiers nécessaires, sans supposer que chaque agent connaît le travail des autres.

## Garder les responsabilités visibles

Le tableau du projet montre qui porte la demande et quels résultats attendent une revue. C’est utile lorsque finance, opérations, marketing ou direction contribuent au même dossier. Ton équipe décide quand les documents sont suffisamment fiables pour être diffusés.

Tale coordonne la demande et sa revue. Les éditeurs de documents restent utiles pour les derniers ajustements et la collaboration dans un fichier. Les chiffres et affirmations à fort enjeu demandent toujours une vérification par une personne compétente.

Commence par un rapport récurrent de ton équipe.
