# Contrat de tâche pour un agent

Copie ce document pour une mission délimitée. Remplace les champs entre crochets, supprime les lignes sans objet et conserve le contrat rempli avec la tâche. Une mission est prête quand son responsable peut expliquer les entrées, le résultat attendu, les actions permises et les critères de revue sans renvoyer à une conversation non consignée.

## Extrait rempli — audit fictif d’un manuel

Ces éléments inventés montrent une partie remplie du contrat et de sa transmission. Ils illustrent un raisonnement ; aucune exécution d’agent ni aucun résultat produit n’ont été observés.

| Responsable de la synthèse | Un rédacteur désigné est responsable de la révision proposée du manuel |
| Conflit | Le manuel r6 dit que chaque membre peut inviter des utilisateurs ; la référence r12 exige un administrateur ; la note S-08 rapporte une invitation depuis un compte standard |
| Appréciation des sources | Le manuel est l’objet de la vérification ; S-08 établit une expérience rapportée non vérifiée ; r12 fait référence pour les permissions documentées |
| Correction proposée | « Un administrateur envoie l’invitation » |
| Question ouverte | Le responsable produit doit déterminer si S-08 concerne un autre rôle, une autre configuration ou une référence erronée |
