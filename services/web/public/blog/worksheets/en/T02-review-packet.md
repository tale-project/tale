# Review packet for agent work

Copy this packet for one decision. Choose exactly one primary decision type below. Complete the matching section and remove the others; if the work needs several decisions, create linked packets. Keep the decision attached to the artifact or operation version actually reviewed.


## Filled excerpt — synthetic announcement decisions

These linked example packets show different decisions over invented material. They are not recorded approvals or deliveries. In the article's scenario, note P-17 applies from Monday to the regional support team and requires escalation of unresolved access problems to the duty lead.

| Packet | Requested decision and evidence | Recorded example decision | Next step |
| --- | --- | --- | --- |
| R-02: result review | Announcement r2 says “All support teams must escalate access problems immediately”; compare with P-17's audience, unresolved condition, and effective date | Request changes: restore all three conditions | Return the specified corrections to the drafter |
| R-03: result review | Announcement r3 restores the three conditions; compare the exact revision with P-17 | Accept r3's accuracy | Use that revision in a separate distribution proposal |
| A-03: action approval | The r3 send proposal targets `all-support`; the trusted task permits only `regional-support-test` | Reject the wrong destination | Correct the operation and request a fresh action decision |

The reviewer must verify the actual destination identity or membership before approving the corrected proposal. Accepted wording does not authorize the rejected audience. This excerpt ends before any corrected operation is approved or attempted; delivery remains unobserved.
