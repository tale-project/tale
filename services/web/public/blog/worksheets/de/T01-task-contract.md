# Aufgabenvereinbarung für Agenten

Kopiere dieses Dokument für einen klar begrenzten Auftrag. Ersetze die Felder in eckigen Klammern, entferne unpassende Zeilen und bewahre die ausgefüllte Vereinbarung bei der Aufgabe auf. Ein Auftrag ist bereit, wenn die verantwortliche Person Eingaben, erwartetes Ergebnis, erlaubte Aktionen und Prüfkriterien erklären kann, ohne auf ein undokumentiertes Gespräch zu verweisen.

## Ausgefüllter Ausschnitt – fiktive Handbuchprüfung

Diese erfundenen Einträge zeigen einen ausgefüllten Teil der Vereinbarung und seiner Übergabe. Sie veranschaulichen die Überlegungen; es wurde weder ein Agentenlauf noch ein Produktergebnis beobachtet.

| Vereinbarungsfeld | Ausgefülltes Beispiel |
| --- | --- |
| Eigenständiger Beitrag | Handbuch r6 mit genehmigter Produktreferenz r12 vergleichen; die andere Prüfung untersucht Kundenfragen |
| Verantwortung für die Zusammenführung | Eine benannte Handbuchredaktion verantwortet die vorgeschlagene Überarbeitung |
| Widerspruch | Handbuch r6 sagt, alle Teammitglieder könnten Personen einladen; Referenz r12 verlangt einen Admin; Supportnotiz S-08 berichtet von einer Einladung durch ein Standardkonto |
| Quellenbewertung | Das Handbuch wird geprüft; S-08 belegt eine ungeprüfte berichtete Erfahrung; r12 ist für dokumentierte Berechtigungen maßgeblich |
| Vorgeschlagene Korrektur | „Ein Admin versendet die Einladung“ |
| Offene Frage | Die Produktverantwortung muss klären, ob S-08 eine andere Rolle, Konfiguration oder fehlerhafte Referenz betrifft |
| Bereitschaft zur Zusammenführung | Teilweise: Keine Erklärung für S-08 als gesichert darstellen; den betroffenen Abschnitt blockiert lassen, falls die verantwortliche Person die Regel nicht bestätigen kann |

Ersetzt r13 die Version r12, prüfe den Berechtigungsbefund vor der Abnahme der Korrektur erneut. Die Prüfung der Kundenfragen kann weiterhin nutzbar sein, weil ihre Eingaben unverändert sind. Eine Teilabnahme muss im vereinbarten Verfahren erlaubt sein; andernfalls wartet das gesamte Ergebnis.
