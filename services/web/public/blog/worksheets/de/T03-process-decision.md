# Entscheidungsblatt für Workflows und Agenten

Nutze dieses Arbeitsblatt, bevor du einen Workflow, einen Agenten oder eine Kombination auswählst. Fülle zuerst Prozess und Abnahme aus. Dokumentiere Unbekanntes als unbekannt; mache aus fehlenden Messungen keine Nullwerte.

## Ausgefüllter Ausschnitt – fiktiver Feedbackbericht

Diese erfundenen Eingaben zeigen eine Entwurfsentscheidung, keinen Benchmark oder beobachteten Modellversuch.

| Entscheidungsfeld | Ausgefülltes Beispiel |
| --- | --- |
| Unveränderliche Zählregel | Nach der vereinbarten Regel eine Zeile je Feedbackkennung behalten; 22 Zeilen minus zwei wiederholte Kennungen ergeben 20 eigenständige Feedbackeinträge |
| Vormonatszahlen | Einrichtung 4, Abrechnung 6, Zuverlässigkeit 5, Sonstiges 5: insgesamt 20 |
| Aktuelle Monatszahlen | Einrichtung 8, Abrechnung 5, Zuverlässigkeit 4, Sonstiges 3: insgesamt 20 |
| Abgenommene Rechnung | Der Anteil Einrichtung am erfassten Feedback steigt von 20 % auf 40 %, also um 20 Prozentpunkte |
| Unbelegte Interpretation | „40 % der Kunden haben Schwierigkeiten bei der Einrichtung“ verwendet einen Kundennenner, den der Export nicht belegt |
| Abgelehnte Ursachenbehauptung | Zwei Kommentare zur Anmeldung und eine Versionsnotiz aus demselben Monat belegen nicht, dass die Veröffentlichung den Anstieg verursacht hat |
| Gewählter Aufbau | Definierte Validierungs- und Zählschritte, anschließend eine begrenzte Untersuchung, wenn neue Erkenntnisse die nächste zulässige Quelle bestimmen |
| Geschütztes Ergebnis | Abgenommene Zahlen und Originaleinträge erhalten; vorgeschlagene Themenmarkierungen getrennt halten |

Die Untersuchung kann aus den drei einladungsbezogenen Einträgen eine Prüfung der Einladungsanleitung empfehlen, ohne eine gemeinsame Ursache festzustellen. Eine reine Zählaufgabe braucht keinen Agenten; ein vollständiges kurzes Belegpaket möglicherweise nur einen Modellschritt. Bei widersprüchlichen Versionen derselben Kennung braucht es vor der Abnahme der Zahlen eine durch die verantwortliche Person definierte Ausnahmeregel.
