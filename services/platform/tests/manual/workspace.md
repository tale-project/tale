# Workspace panel — Manual Test Plan

> **Purpose**: Exercise the unified chat side panel — the Canvas (agent-written
> files, code-run output, the file viewers), the read-only Workspace-files
> explorer, the Live-browser stream with human takeover, the Research-plan pane,
> and the composer Sandbox pill. All content in this panel is produced by agent
> tool calls, so nearly every case needs mode B; external-agent cases
> additionally need the Docker sandbox runtime. The conversation surface itself
> is [chat.md](chat.md)'s.

## Scope & routes

| Surface                     | Route                              |
| --------------------------- | ---------------------------------- |
| Chat panel (all four panes) | `/dashboard/{org}/chat/{threadId}` |

(The panel has no route of its own — it appears inside a thread once a pane has
content; `{threadId}` is produced by sending a first message.)

## Prerequisites

Bring the stack up and sign in per [SETUP.md](SETUP.md). **Mode A** is the
hermetic mock stack; the mock never emits tool calls, so every case except F1
needs **mode B** — a live provider plus a platform agent that has the
`file_write` / `run_code` tools (the built-in assistant ships with them, per
`builtin-configs/agents/chat/assistant.json`). Explorer, live-browser, and
sandbox-pill cases additionally need the Docker sandbox runtime: **mode
B+sandbox** = repo-root `bun run dev` (NOT `dev:fast`, NOT
`TALE_DEV_SKIP_DOCKER=1`) plus an **external agent** (Settings → Agents, type
**External agent**, `settings.agents.form.agentType.externalLabel`).

> **Agent note**: panes register into one right panel with three states —
> absent (no content), a 48 px minimized strip, and a maximized tab bar. All
> visible pane bodies stay **mounted** — inactive ones carry the `hidden`
> attribute — so assert visibility, not DOM presence. Wait on structure, not
> timing: the Canvas is ready when a `role="tab"` with the filename appears; a
> streaming write shows a **Writing…** meta that disappears when the file
> lands; the Live browser is ready when the polite `role="status"` text
> **Live** (`chat.liveBrowser.streaming`) appears. Turn completion is the
> Send⇄Stop toggle from [chat.md](chat.md).
