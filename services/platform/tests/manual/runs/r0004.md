### R4-1 · Native nullable credential state

The contract accepts nullable native timestamps, and status/actions use a
null-aware check. A component regression verifies active credentials remain
revocable and revoked rows have no action. A real create/use/revoke sequence
confirmed the backend refused the revoked password afterward.

### R4-2 · DAV discovery through Vite

Vite now lets preflight continue to the backend while retaining its default
allowed origins. A regression starts real development and preview servers and
checks DAV/Allow headers and the absence of a foreign-origin CORS grant. The
running platform returned 200 with DAV headers after the change.

### R4-3 · Contact and product dates

The existing read adapter maps native timestamps to the table fields for both
simple and paginated lists, preserving native fields and cursor metadata.
`app/lib/backend/engagement.test.ts` pins the mapping. Fresh local records now
display their actual dates instead of a dash.

### R4-4 · Readable credential badges

Label/status content can wrap and the shared badge cannot shrink. Six real
browser cases confirmed badge content width fits in EN/DE/FR at 1440px and
390px. `SET-A7` and its pin preserve the visual judgment. The reproducible
WebDAV fixture includes a clearly named retired device.

### R4-5 · Authoritative screenshot readiness

The seeder waits for the table's output footer instead of any status region.
Two real-browser regressions recreate a delayed query beside unrelated status
messages; both fail with the former selector and pass with the corrected one.
The final specs run in the Playwright E2E lane, which installs Chromium in CI.
A full seed rerun completed without trying to recreate existing knowledge rows.
Independent review also found that a retired device label could satisfy the
active device substring check. Exact label matching and a retired-only DOM
regression now preserve partial fixture recovery.

### R4-6 · Honest CLI completion text

The no-env branch explains the remaining environment setup. Normal completion
asks the operator to preserve keys and review deployment configuration. The
compiled CLI smoke test checks the no-env output and absent `.env` file.

### R4-7 · Connector scope

English, German and French settings copy now describes workflow actions and
supported agent integrations. The docs explain tool exposure as a separate
configuration step. The credential-picker screenshot was retaken afterward.
