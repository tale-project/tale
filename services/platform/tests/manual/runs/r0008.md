## Scope

Exercise captured reviewer ownership, stale handoff, live native verdicts and
localized task/project reviewer controls on a local instance. This is a scoped
acceptance round for the independent agent-review change. Its session logs,
screenshots, DOM bounds and authenticated tool receipts are retained outside
the repository; evergreen suite boxes remain empty.

The two identity sessions used separate localhost and 127.0.0.1 cookie origins
and distinct Owner and Editor accounts. The Owner's ordinary logout did not
sign out the Editor, whose identity remained visible after reload. Local native
verdicts used the actual authenticated tool route with inert source/issuer runs;
no agent model was executed and no production permission or fixture was changed.

## Baseline

checks and the manual guide guard were green before the first browser pass.
The full workspace gate was scheduled after the bounded browser work, so this
round does not claim a fully green untouched baseline. Its later combined gate

benign. The Owner's sign-out/navigation cleared some earlier browser console

### R8-1 · Reviewer picker exceeds phone width

**Surface** Task Reviewer and project Default reviewer. **Repro** Open the
localized reviewer picker with its help footer at 375 px. The panel's intrinsic
minimum exceeded the viewport, clipping search and guidance. The shared
`SearchableSelect` now bounds minimum and maximum width by the Radix available
width, with the existing 8 px collision inset. Desktop trigger width remains
respected.

**Pinned by** `packages/ui/src/components/forms/searchable-select.browser.test.tsx`:
real Chromium long-footer and oversized-trigger regressions, plus a desktop
width and keyboard-selection control. The original red run had two failures
and one passing desktop control; the final browser suite and localized UI
observations passed.

### R8-2 · Localized picker exceeds available height

**Surface** Shared picker content, including the switcher variant. A
width-contained localized menu could still exceed its available height. The
existing Popover height bound now applies to `SearchableSelect`; horizontal
containment no longer disables the switcher's vertical scrolling.

**Pinned by** The same actual-browser suite at 375×430, with 20 options and a
long German footer in each variant. Search, footer and the last option remain
reachable; End/Enter and Escape preserve selection and focus behavior. Both
new cases failed before the height repair while the three width/desktop
controls passed. Final EN/DE/FR task and project views were re-driven in Chrome.

## Not reached

This is not a pass over the complete manual catalogue or every clause of
`TASK-F63` and `TASK-A15`. Full screen-reader coverage, a real model reading the
staged files and an automation-owned captured-review browser fixture were not
run. Actual component regressions cover the reachable captured-review panel,
loading/error controls and stale confirmation closure on handoff and recovery.
Later actual-component regressions also require a fresh gesture after the task
leaves review, after loading, after replacement of the captured approval/run,
and when a different task uses the same workflow. An unchanged review stays
open; feedback survives the reset. These UI guards do not add a human-verdict
compare-and-set contract to the server.

The task chooser's generic caption/refusal for an agent without the review
grant remains a separate precision concern; the backend refused the choice
and retained B. It is not counted as a confirmed additional defect here. The
prefetch/preload console warnings also remain separate triage observations.
An unexpected sign-out confirmation during one tightly batched controller
sequence was canceled and the session retained; this is recorded as controller
ambiguity, not an established product finding.

## Verdict

Both concrete mobile defects were fixed, pinned by actual-browser regressions
and re-driven in all three locales. All owned tabs and local servers were
closed normally; the global viewport was restored to 1587×827. The two-identity
functional evidence predates the later shared picker styling, the
static-message/type-import guard repair, and the final confirmation-state
guards. The picker was re-driven in all three locales; confirmation transitions
were checked in the real component, not re-claimed as browser observations.

The final bound local workspace gate passed all 58 tasks: 45 were cached and
13 executed. Fresh platform results were 5,147 UI tests and 81,219 server
tests, with five existing server skips. The unchanged local Knip baseline
remains 86 diagnostics in the reused dependency layout; no new diagnostic was
introduced. Final main integration and hosted checks remain publication gates.
The automation register owns the new regressions; evergreen boxes were not
ticked or renumbered.
