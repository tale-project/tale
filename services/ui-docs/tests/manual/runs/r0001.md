## Scope

Read all 19 English guides against the package source, reviewed the EN/DE/FR chrome
catalogs, and rendered every guide at both widths in both themes. Exercised settings,
notifications, dialogs, tabs, inputs, table search, source panels, theme persistence,
keyboard entry, and the phone drawer. The site intentionally has English body routes.

## Baseline

This round continued the documentation overhaul after the UI consolidation, rather
than starting from an untouched tree. Initial observations exposed the four defects
below; their failing tests and browser evidence were retained outside the clone.
A later complete service test run also caught an incomplete MediaQueryList test mock;
it now supplies event methods explicitly instead of spreading a class instance.

## Findings

| ID | Severity | Box | What |
|---|---|---|---|
| R1-1 | `bug` | `DOCS-4` | Settings Save did not establish a new baseline; Discard restored the original fixture. |
| R1-2 | `bug` | `DOCS-4` | Toast examples mounted separate viewports over one global store and duplicated notices. |
| R1-3 | `bug` | `SMOKE-5` | Scrolling the active rail row into view changed the initial keyboard position and bypassed the skip link. |
| R1-4 | `bug` | `DOCS-6` | Outline navigation requested smooth scrolling even with reduced motion enabled. |

### R1-1 · Settings baseline

**Fix** Store the local saved values separately; Save adopts the draft and Discard
restores that saved baseline. Explain that reload resets this demonstration.
**Pinned by** `tests/e2e/specs/demo-workflows.spec.ts` settings workflow.

### R1-2 · Duplicate notification viewports

**Fix** Mount one `Toaster` in the root route and let both examples trigger it.
**Pinned by** `tests/e2e/specs/demo-workflows.spec.ts` toast workflow, including replacement.

### R1-3 · Initial keyboard position

**Fix** Adjust the rail container’s scroll position without `scrollIntoView` on its
active row. **Pinned by** `tests/e2e/specs/demo-workflows.spec.ts` first-Tab/skip-link test.

### R1-4 · Motion preference

**Fix** Read the current reduced-motion media query and use instant scrolling when
requested. **Pinned by** `app/components/docs/docs-toc.test.tsx`, both preference states.

## Not reached

This was a content-and-example round, not a complete execution of the manual catalog.
Clipboard contents, detailed scroll-spy transitions, drawer resize while open,
search recents/clearing, print, and every security-header assertion were not independently
repeated. Composition excerpts that depend on host routes or backend callbacks were
source-reviewed; the examples do not establish real backend persistence or authorization.

## Verdict

All four defects are fixed and pinned. The final service checks passed: 94 unit tests,
12 browser specs, typecheck, lint, production build, and React Doctor (100/100).
All 76 rendered guide cases and the complete interaction observer passed, as did 44
built endpoint checks. The PR-wide gate remains recorded by the root review rather
than being implied by these service results. Detailed logs, source hashes and screenshots
are in the external `docs-overhaul-2026-09-14/rebase2` review notes.
