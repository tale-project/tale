title: Discussions
description: Threaded, multi-participant conversations inside a project — ask questions and make decisions, with agents joining when you @mention them.
---

**Discussions** (a project's Discussions tab) are threaded conversations that live with a project, alongside its tasks and chats. Use them the way a team uses a discussion board: open a topic, talk it through, and resolve it — with the AI workforce one @mention away.

They reuse the chat message surface, so a discussion reads and composes like a chat, but it belongs to the project and is visible to every project member (not just its author).

## Opening and replying

**New discussion** asks for a title, a category, and an opening message. Replies work like any message box. Discussions are **human-first**: your post is always saved, and an agent only responds when you bring one in.

- **@mention an agent** in your message and that agent replies in the thread — the same routing and generation as chat.
- With no @mention, the post is just a message between people; no agent is summoned.

## Categories and lifecycle

Each discussion has a **category** (general, Q&A, ideas, decisions, announcements, show-and-tell, polls) to keep the board organized.

Its **lifecycle** is independent of that:

- **Open** — active.
- **Resolved** — the question is answered or the decision is made (reopen anytime).
- **Locked** — no further replies.

## Turning a discussion into work

**Create task** spawns a task on the project board from the discussion, with a link back to the conversation it came from — so a decision made in a discussion becomes trackable work without retyping it.
