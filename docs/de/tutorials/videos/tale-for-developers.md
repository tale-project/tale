Alles, was die Serie gezeigt hat, trägt eine API darunter. Die Bonus-Episode geht die Entwickler-Oberfläche ab: benannte, widerrufbare API-Schlüssel; REST, MCP, WebDAV und Sandbox-Runtimes; Webhooks, die Agenten aus jedem System auslösen; die Sandbox-Agents — Claude Code, Cursor — in ihren Harnesses; und die Run-Code-Richtlinie, die benennt, was installiert werden darf und wohin Code sich verbinden darf. Starke Werkzeuge, eingehegter Wirkungsradius.
