title: Bildgenerierung
description: Bildgenerierung gibt es in dieser Version nicht — es gibt kein Tool generate_image, und kein Agent erzeugt Bilder in seiner Antwort.
---

Diese Seite hat früher `generate_image` beschrieben, ein Tool, das jeder Agent gewährt bekommen konnte, um ein Bild direkt in seiner Antwort zu erzeugen. Weder das Tool noch eine Gewährung pro Agent existiert in dieser Version von Tale: Die Tools des Chat-Assistenten stehen fest und liefern nur Text, und kein Bildmodell hängt an einer Antwort. Die Seite bleibt, damit das Fehlen dokumentiert ist, statt entdeckt zu werden.

<Note>

Bildgenerierung ist in dieser Version nicht verfügbar. Bittest du den Assistenten, etwas zu zeichnen oder zu entwerfen, bekommst du Text und kein Bild.

</Note>

## Was du heute mit Bildern tun kannst

Bilder reisen als Dateien. Häng sie an eine Aufgabe — das Aufgaben-Sheet nimmt Bilder und Dokumente per Ablegen oder Einfügen an —, und ein Projekt-Agent, der diese Aufgabe bearbeitet, findet sie unter seinen Eingabedateien. Dokumente, die du unter [Wissen](/de/platform/knowledge/overview) hochlädst, werden für die Suche indexiert, und die Ergebnisse, die ein Projekt-Agent erzeugt, landen zur Prüfung auf der Aufgabe; [Aufgaben-Automatisierung](/de/platform/projects/task-automation) behandelt diese Schleife.

Welche Modelle deine Organisation überhaupt nutzen darf, ist eine Frage der [Provider](/de/platform/admin/providers), entschieden unter **Einstellungen > KI-Anbieter**; ein bildfähiges Modell in dieser Liste fügt dem Chat kein Zeichen-Tool hinzu.

## Wo das hingehört

Bilder zu erzeugen ist keine Fähigkeit, die diese Version bietet; kein Agent, keine Richtlinie und kein Budget muss also dafür geradestehen. Braucht dein Ablauf ein Bild, behandle es wie jede andere Datei: Häng es an die Aufgabe und prüf es dort.
