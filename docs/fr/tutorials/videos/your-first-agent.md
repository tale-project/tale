Le chat t’a appris à demander ; les connaissances, sur quoi reposent les réponses. Cet épisode construit ce qui met les deux au travail : un agent, créé de zéro à l’écran. Le fil rouge est la frontière de confiance — chaque outil accordé élargit ce que l’agent peut faire. Le plus petit agent qui fait le travail est le plus sûr.

<Note>

L’épisode a été enregistré dans l’ancien éditeur d’agent. La liste des agents, la boîte de dialogue de création, les onglets **Connaissances** et **Outils** et l’étape « visible dans le chat » ne font pas partie de cette version — les agents que tu crées aujourd’hui vivent dans l’onglet **Agents** d’un projet et traitent les tâches du tableau, et le chat n’a pas de sélecteur d’agent. Regarde-le pour le raisonnement ; prends les étapes dans [Construire ton premier agent](/fr/tutorials/editor/first-agent-end-to-end).

</Note>
