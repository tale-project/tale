## Trouver ton point de départ

Ton rôle détermine les actions disponibles. Les équipes et l’accès aux projets déterminent les ressources accessibles. Choisis le parcours le plus proche de ton travail ; un administrateur peut expliquer une action absente.

<CardGroup cols="2">

</Card>
