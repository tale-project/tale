title: Nouveautés
description: Consulte les notes de version et repère les changements qui concernent ton équipe.
---

Ouvre **Nouveautés** pour lire les notes de version de Tale. Tous les membres connectés peuvent les consulter, sans rôle d’administrateur.

## Ouvrir les notes de version

Utilise **Nouveautés** dans le menu utilisateur ou **Voir** dans une notification de mise à jour. Ouvrir les notes marque la mise à jour comme lue et retire son indicateur. La page présente les versions concernées, ou indique que tu es à jour.

Déplie une version pour lire son numéro, sa date, son titre et ses notes. Repère les changements qui touchent les tâches de ton équipe, puis consulte les guides liés pour retrouver les instructions actuelles.

## Trouver des notes anciennes ou indisponibles

Utilise le lien vers les anciennes versions sur GitHub si le changement recherché dépasse la période affichée. La page récupère les informations publiques de GitHub et les met en cache. Sans accès réseau, un déploiement peut ne pas charger les notes absentes de son cache.

Une version encore non publiée peut ne pas avoir d’entrée correspondante. Consulte l’historique lié : une vue vide ne prouve pas qu’aucun changement n’a eu lieu.

## Distinguer versions et activité de l’organisation

Les notes décrivent les changements de Tale lui-même. Pour savoir qui a modifié les paramètres ou le contenu de ton organisation, consulte plutôt [les journaux d’audit](/fr/platform/admin/governance/audit-logs).

Si tu exploites un déploiement, suis [le guide de mise à jour](/fr/self-hosted/operate/upgrades), puis lis les notes pour identifier ce que ton équipe doit savoir.
